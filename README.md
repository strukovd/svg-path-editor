## Точка входа
В [SceneStore.ts](/src/stores/SceneStore.ts#L5-L6) определен path рисунок




Разбор структуры:
Есть один SVG, внутри которого сначала рисуются линии (<line>, только в пределах видимости, сначала жирные 0, 0, затем остальные), затем рисуется обыкновенный path, внутрь которого помещается провализированный код из редактора, затем рисуются поперечные линии (<line>) (для кривых безьё), а затем уже сами точкт (<cirle>) всех элементов (линий, безьё, arc, и прочее)
